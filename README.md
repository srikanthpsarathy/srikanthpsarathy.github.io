# Sparkle Brush Timer 🦷✨

A cartoon, kid-friendly tooth-brushing timer built for a 4 year old.

Open `index.html` (or visit this site once GitHub Pages is enabled) to use it —
no build step, no dependencies, just a single static page.

## How it works

- **4 zones, 30 seconds each** — Top Left, Top Right, Bottom Left, Bottom Right —
  for a full 2 minutes of brushing, matching dentist-recommended brushing time.
- A cartoon mouth (**Sparkle**) shows a highlighted color and an animated
  toothbrush scrubbing over whichever zone is currently active, so a young
  child can follow along without reading.
- A circular countdown ring shows seconds left in the current zone, and a
  rainbow progress bar shows how much of the whole mouth is done.
- Friendly chime sounds play when moving to a new zone, with a fanfare and
  falling confetti at the finish (synthesized in-browser, no audio files).
- Big, bright, tap-friendly Start / Pause / Reset buttons for small hands,
  plus a mute toggle.

## Files

- `index.html` — the entire app (HTML + CSS + JS), self-contained.
